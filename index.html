PLATFORM / POLICY

Control settings

HAWK behaves like a remote control, never a media server.

Independent playback

Once approved, each TV securely saves its configuration and streams directly from its DVR. Cloud or laptop outages do not revoke existing playback. Only an explicit administrator command can suspend an approved installation when it next checks in.

No payment automation

No subscriptions, expiry timers, payment records, automated suspension or billing.

TV error handling

Users receive simple, specific guidance for interrupted streams or network failures. DVR credentials and technical diagnostics stay hidden.
